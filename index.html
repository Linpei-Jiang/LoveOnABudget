Game Overview

Single Player

Love on a Budget is a single player dating simulation, players will need to live for 5 days and play mini-games to gain enough points to win.

Multiple Stories

There is more than 1 story in the game, each choice you pick when given an option can lead you to a different branch that leads ether to victory or loss.

Multiple Endings

Multiple stories leading to different endings, not just simply "win" or "loss". But does give user some hints on why it caused them to have that result.

Java Based

The mini games are based on Java programing, mainly focusing on AP CSA and Data Structure students working with Java Programming.
